COMMUNITY LIBRARY MANAGEMENT — HTML VERSION

OPEN THE APP
1. Download and extract the ZIP.
2. Open the Community-Library-HTML folder.
3. Double-click index.html.
4. The app opens in your browser. No React, npm, Node.js, or server is needed.

FILES
- index.html: page structure
- style.css: design and responsive layout
- app.js: application logic and localStorage

FEATURES
- Dashboard with total titles, available copies, borrowed copies and registered users
- Low-stock list
- Add, edit, search and delete books
- Add, edit, search and delete users
- Record borrowing and returns with quantity validation
- Transaction history
- Saves data in this browser

IMPORTANT
Keep all three files in the same folder. The data is saved only in the browser/device where you use it. This is a front-end coursework demo, not a secure multi-user online database.
